Project Description
The Login and Sign-Up Web Application is a simple website designed to demonstrate the basic process of user login and account registration. It provides a user-friendly interface where users can enter their username or email and password to log in, or fill out a registration form to create a new account.
The project uses HTML to structure the web pages, CSS to style the interface, JavaScript to validate user input and display feedback messages, and the Bulma CSS framework to create a clean and responsive design.
This project aims to demonstrate the basic concepts of web development, including form handling, input validation, and interaction between HTML, CSS, and JavaScript.

Features
Login Page – Allows users to enter their email or username and password.
Sign-Up Page – Provides a registration form for full name, email, username, password, and password confirmation.
Form Validation – Checks whether required fields have been filled in.
Password Confirmation – Checks whether the password and confirm password fields match during registration.
Feedback Messages – Displays success or error messages based on the user's input.
Responsive Design – Uses the Bulma CSS framework to help the interface adapt to different screen sizes.
Simple Navigation – Allows users to switch between the Login and Sign-Up pages.

Technologies Used
HTML5 – Structures the login and registration pages.
CSS3 – Customizes the layout, background, spacing, and appearance of the forms.
JavaScript – Handles form submission, input validation, and feedback messages.
Bulma CSS – Provides styling components and responsive layout utilities.

Project Files
index.html – Contains the Login page.
signup.html – Contains the Sign-Up page.
style.css – Contains the custom CSS styles.
script.js – Handles form validation and displays feedback messages.

How to Run the Project
Download or clone this repository.
Make sure all project files are in the same folder.
Open index.html in a web browser.
Use the Login page or click Sign Up to open the registration page.
Enter the required information and observe the validation and feedback messages.
